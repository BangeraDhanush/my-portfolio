## 🚀 Deployment

This is a static website with Three.js loaded from a CDN. No build step is required.

1. Upload every project file to the root of your GitHub repository.
2. Make sure to upload **ALL files and folders**, including:
   - `assets/`
   - `resume-data.js`
   - `index.html`
   - CSS and JavaScript files
3. Go to **Settings → Pages**.
4. Under Build and Deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Click **Save**.

Your website will be available at:

[https://bangeradhanush.github.io/my-portfolio/](https://bangeradhanush.github.io/my-portfolio/)
